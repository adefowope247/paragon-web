ParagonEdu Web - Phase 1 (Foundation)
=====================================

WHAT THIS IS
  The beginning of the browser version of ParagonEdu Suite. Phase 1 has:
  login (matches your desktop accounts), a dashboard with live counts, and
  the Students module (searchable, class-filtered list + detail page).
  It reuses your desktop app's database format - point it at a real
  school_data.db and it shows that school's students.

ONE-TIME SETUP (on the PC that will run it)
  1. Make sure Python is installed (you already have it).
  2. Put all these files in one folder, e.g. C:\Users\USER\Desktop\ParagonWeb
       app.py  webdb.py  requirements.txt
       templates\   (the .html files)
       static\style.css
  3. Install the web libraries (one time):
       pip install fastapi "uvicorn[standard]" jinja2 python-multipart itsdangerous --break-system-packages

RUN IT
  In Command Prompt, from the folder:
       cd C:\Users\USER\Desktop\ParagonWeb
       python -m uvicorn app:app --host 0.0.0.0 --port 8000
  Then open a browser to:  http://localhost:8000
  On first run it creates a demo database so you can log in immediately:
       Username: admin    Password: admin123   (role: Administrator)

USE YOUR REAL SCHOOL DATA
  Point it at an existing ParagonEdu database before starting:
       set PARAGON_DB=C:\Users\USER\AppData\Local\ParagonEduSuite\school_data.db
       python -m uvicorn app:app --host 0.0.0.0 --port 8000
  Now it shows that school's real students, and existing logins work
  (case-insensitive, same as the desktop app).

OTHER PCs ON THE SAME NETWORK
  Because it runs with --host 0.0.0.0, other devices on the same wifi can
  reach it at  http://<this-pc-ip>:8000  (find the IP with: ipconfig).

WHAT'S NEXT (future phases)
  Phase 2: Scores entry (with the class-subjects rule we built).
  Phase 3: Report cards / results view (for parents & students online).
  Phase 4: Fees, then the rest - each module rebuilt to match the desktop.
  Then: move to PostgreSQL + proper hosting for many schools online.

NOTE

PHASE 5 ADDED: THEORY EXAMS (type answers, on-screen marking, review)
------------------------------------------------------------
  TEACHER/ADMIN (sidebar -> "Theory Exams"):
    - "+ New theory exam": title, subject, class, duration, mode, instructions.
        mode = "Type answers on screen"  OR  "Hybrid (read on screen, write on paper)".
    - Add questions with marks + an optional model answer. English passages,
      lexis & structures with TITLES are supported (line breaks preserved).
    - "Scripts": see who submitted; "Mark" opens the on-screen marking page -
      read each typed answer, award marks (capped to the question's max), add a
      note, Save & finalize -> computes the total.
  STUDENT (sidebar -> "Theory Exams"):
    - Sees exams for their class. "Start" opens a TIMED exam: live countdown,
      types answers, auto-submits when time hits 0.
    - After the teacher marks it, "View script" shows their answers, the score,
      and the teacher's notes.
  HYBRID mode: questions show on screen with the countdown; no typing box -
    students write on paper and submit to the teacher.

  STILL TO COME (need hosting first): image upload in questions/answers, and
  math-expression input/rendering. Special characters & line-broken passages
  already work today.

PHASE 6 ADDED: MCQ CBT (JAMB / WAEC / NECO / School objective tests)
------------------------------------------------------------
  Sidebar -> "CBT (Objectives)".
  TEACHER/ADMIN:
    - Question Bank: add A-D questions per subject, per exam type
      (School / WAEC / NECO / JAMB). Each exam type has its own bank.
    - "+ New CBT test": pick exam type (presets fill sensible defaults -
      JAMB = 4 subjects/120 min, WAEC/NECO = 50Q/60 min, School = flexible),
      choose subjects, questions-per-subject, duration.
    - OPTIONAL results link: set a test to fill CA1 / CA2 / Exam for an
      academic subject. After students finish, open the test's "Scores" and
      click "Send to score entry" -> the CBT % is SCALED to that field's max
      and written into the result/report card (teacher-confirmed, not auto).
  STUDENT:
    - Sees CBT tests for their class. "Start" = timed objective test with
      A-D options and a live countdown; auto-submits at 0; auto-scored
      instantly; sees score + percentage.

  IMPORT YOUR DESKTOP QUESTIONS:
    On the Question Bank page click "Import from desktop app". It pulls in:
      - cbt_questions  -> the School bank (subject names resolved automatically)
      - exam_questions -> JAMB / WAEC / NECO banks (by their exam_type; UTME -> JAMB)
    Duplicates are skipped, so you can run it again safely after adding more on
    the desktop. (Run the web app with PARAGON_DB pointed at your real database
    so it can see the desktop questions.)

PHASE 7 ADDED: AI Question Generator (local, scheme-driven - no API key)
------------------------------------------------------------
  Sidebar -> "AI Generator" (staff). Paste a SCHEME OF WORK (one topic per
  line; "Week 1:", numbering and bullets are stripped automatically). For each
  topic it builds:
    - MCQ (A-D) pulled from your question bank and varied (option order
      shuffled, correct answer tracked), matched to the topic by keywords.
    - Theory questions: related ones from your theory bank, topped up with
      scaffold prompts around the topic (with marks).
  Tick "keep" on the ones you want and click "Save kept questions to bank":
    - MCQ go into the chosen exam-type bank.
    - Theory go into a new "Generated Theory - <subject>" theory exam.
  It works fully OFFLINE from your existing questions (no API key). The richer
  your bank (import your desktop questions first!), the better it generates.
  If/when you add an Anthropic API key + hosting later, true generative AI can
  be layered on top of this same page.

PHASE 8 ADDED: FINANCE SUITE (admin/bursar only)
------------------------------------------------------------
  Sidebar "Finance" now has Fees, Debtors & Arrears, Expenses, Accounts & Report.

  DEBTORS & ARREARS (/debtors):
    - Every student who owes, with TWO separate columns:
        "This term" = current term outstanding
        "Arrears"   = unpaid balances carried from PAST terms (same session)
    - Term totals at top; "Remind" opens a WhatsApp message to the parent with
      the breakdown (arrears + this term + total).

  EXPENSES (/expenses):
    - Record school spending: date, category (Salaries, Supplies, Maintenance,
      Utilities, Transport, Rent, Feeding, Examination, Others), amount, paid-to,
      method, description. Filter by category; delete rows. Term totals + top
      categories shown as stats.

  ACCOUNTS & REPORT (/accounts):
    - Income (fees collected) vs Expenses = Net balance, for the current term.
    - Expected fees + still-outstanding for context, expenses by category.
    - "Download report PDF" = a clean Financial Report (with your logo).

  EXPENSES ARE NOW UNIFIED WITH THE DESKTOP:
    The web Expenses module reads and writes your real desktop `expenses` table
    (title, amount, category, expense_date, session, term, payment_method,
    vendor, receipt_no, recorded_by, note). Categories come from your
    `expense_categories` table. So an expense recorded on EITHER app shows up in
    BOTH, and the Accounts report counts them all. (Run the web app with
    PARAGON_DB pointed at your real database.)
